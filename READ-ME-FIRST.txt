TAIYABAH MASJID — bigger text, readable gold
============================================
14 September 2026

14 files. Every one is a replacement for a file already in the repository —
nothing new is added, nothing has to be deleted.


HOW TO UPLOAD (github.com, no command line needed)
--------------------------------------------------
1. Open https://github.com/yameenbux/Taiyabah-Mosque-Website-Rebrand
2. Make sure you are on the branch you want to change.
3. "Add file" -> "Upload files".
4. Unzip this first, then drag the CONTENTS of the "taiyabah-text-size"
   folder into the browser — not the folder itself, and not this text file.
   The folder structure (access/, venue/, portals/, ...) must be kept: that
   is how GitHub decides which files to replace.
5. Commit.


WHAT CHANGED
------------
Text size. 1,119 sizes across the website and the eleven staff screens were
raised. The small print moved most — a 9.6px label is now 13.3px — and the
big headings did not move at all. Nothing on the site is under 12px now.
Body text is 16.3px instead of 14.7px.

Colour. The masjid gold reads at 2.3:1 on the cream cards, which is well
below the readable minimum. "VIEW FULL TIMETABLE" on the home page was one
of the worst. There are now three darker variants for text — gold, green
and red — and 59 places were switched over to them. Gold on the dark plum
was always fine and has not changed.


FIVE THINGS THAT WERE BROKEN, FOUND WHILE DOING THIS
----------------------------------------------------
1. The donate page's button, when no payment link is set up — which is the
   state it is in right now — said "Not available yet" in cream on cream.
   Invisible.
2. Two buttons in the Five Pillars article were cream on cream for the same
   reason.
3. ON THE SIGN-IN PAGE, the charity registration line was invisible. It had
   been placed outside the plum panel it was styled for, so it rendered as
   pale cream on the pale background. A charity's registration number is
   the one line on that page that has to be legible.
4. The "TAIYABAH MASJID" line above every sign-in form was 1.77:1.
5. The madrasah and new-build pages were being cut off at the right edge on
   a narrow phone, with nothing reporting an error.

All five are fixed in these files.


HOW IT WAS CHECKED
------------------
Every page was measured before and after at four screen widths for text
that gets clipped, buttons whose labels wrap, and columns that push off the
screen — and the two reports compared line by line. The public site's report
is identical to before. Contrast failures went from 22 to 0.

The repository's own 13 test suites were run before and after. Twelve pass
either way. giftaid_test.py fails identically before and after, because
db/022_donations_and_gift_aid.sql is missing from the repository — a known
gap, not something caused by this change.


WHAT IS DELIBERATELY NOT IN HERE
--------------------------------
Nothing from db/, supabase/ or _test/. None of them changed.
