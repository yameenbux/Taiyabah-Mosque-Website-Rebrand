HOW TO UPLOAD (github.com, no command line needed)
--------------------------------------------------
1. Open https://github.com/yameenbux/Taiyabah-Mosque-Website-Rebrand
2. Make sure you are on the branch you want to change (main).
3. Click "Add file" -> "Upload files".
4. Unzip this file first, then drag the CONTENTS of the "taiyabah-upload"
   folder into the browser — not the folder itself, and not this text file.
   The folder structure inside (access/, db/, newbuild/, ...) must be kept,
   because GitHub uses it to decide which files to replace.
5. Write a commit message, e.g.
      User access, the new build editor, the madrasah portal, and the
      admin centre rail
6. Commit.

GitHub will replace the 26 files and leave the rest of the site alone.


ONE THING THE UPLOADER CANNOT DO
--------------------------------
A web upload can add and replace files. It cannot DELETE one.

This branch deletes exactly one file, which is now unused:

    portal/supabase2.112.4.js

Delete it by hand after uploading: open it on GitHub, click the bin icon
(top right of the file view), then commit. The site works either way — it
is dead weight, not a dependency — so this is tidiness, not urgency.

A NOTE ON THE KEYS IN THESE FILES
---------------------------------
access/config.js and newbuild/config.js contain a Supabase key. That key is
the PUBLISHABLE (anon) one and it is meant to be visible — the real
protection is Row Level Security inside the database. It is safe in a public
repository.

The service_role / secret key is NOT in any of these files, and must never
be put in one. If GitHub ever warns you that a push contains a secret, do
NOT click "Allow secret" — cancel, and get the key rotated.
