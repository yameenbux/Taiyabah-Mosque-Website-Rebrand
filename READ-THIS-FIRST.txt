THREE THINGS A ZIP CANNOT EXPRESS
  A zip can add and replace files. It cannot delete them. Run these three in
  your clone before you commit, or the deleted files will still be on the
  live site:

      rm -f img/test
      git rm --cached -f portal/supabase2.112.4.js 2>/dev/null; rm -f portal/supabase2.112.4.js
      git rm --cached -f supabase/functions/index.ts 2>/dev/null; rm -f supabase/functions/index.ts

  (The first is a stray one-byte file. The other two are old copies that were
  moved; leaving them behind serves stale JavaScript to the masjid.)
