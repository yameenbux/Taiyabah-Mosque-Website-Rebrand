The "You are" dropdown now matches every other field
====================================================

Upload:

  index.html
  index_template.html

Replaces the two files from the previous zip — same change plus this fix.


WHY IT LOOKED WRONG
-------------------
The stylesheet had this:

    .cf-row input, .cf-row textarea { ...rounded, cream, our border... }

No `select`. So the browser rendered the dropdown with the operating system's
own widget instead — the small grey box with the native arrow. On a Mac it
would have looked different again, and on Windows different from both.

The giveaway is one line further up: the ERROR state rule DOES list select

    .cf-row.bad input, .cf-row.bad select, .cf-row.bad textarea { ... }

so whoever wrote it remembered the select for the red-border state and missed it
for the normal one. That is why the field went red correctly when left blank but
never looked right the rest of the time.


WHAT I DID
----------
Added select to the base and focus rules, then stripped the native chrome and
drew our own arrow — an inline SVG, so it costs no network request and keeps the
site's rule of loading nothing from anywhere else. The arrow darkens to the
brand colour on focus.

Heights are matched by giving all three controls the same line-height rather
than by pinning a fixed height, so if the padding or font size ever changes they
stay in step instead of drifting apart by a pixel again.

One more thing while in there: the error-state rule used the `background`
shorthand, which would have wiped the new arrow away whenever the field went
red. Changed to `background-color`.


CHECKED, NOT EYEBALLED
----------------------
Border radius, border colour, background, font size and height are now compared
between the select and the text inputs beside it, at 1280px and at 390px:

    name=43px   select=43px   phone=43px

The nikāḥ test now asserts that permanently, plus that the select is no longer
rendering as a native widget. A future field cannot quietly go back to looking
like it belongs to a different website.

Worth knowing: this was the only <select> on the whole public site, so nothing
else was affected. The madrasah form has its own stylesheet and its dropdowns
were already styled.
