What a class says

This is the wording on each class’s own page on the website — the line under the heading, the opening paragraph, the what-to-know list, the session buttons on the form, and the sentence people read when sign-ups are shut. There is no draft here. Notices and the prayer timetable wait for you to publish them; this one does not. Whatever you save is on the website the moment you save it, so read the preview at the bottom first.

A brand-new class is started on the Adult classes screen

This screen writes the words for a class that already exists. Adding one, renaming it, changing how many places it has or opening and closing sign-ups all happen on Adult classes; come back here afterwards to write its page.

A new class does not appear on the website at all until its page here is finished. Half a class page — a heading over an empty body — would look entirely normal and be wrong, so the website skips it instead.

The fact strip beside the form

Up to four, and they can be left out altogether. Both halves are 24 characters at most — they sit in a narrow box on a phone, and a fifth wraps into a mess.

Four facts is as many as the strip will hold. Remove one before adding another.

What to know

Between one and eight rows — when it runs, who it is for, how many places there are. The label is the short half (“When”), up to 28 characters.

Eight rows is as many as the list will hold. Remove one before adding another.
