Set up two-step verification

This screen holds staff records and contact details, so it needs a second factor before you can continue.

  • Install an authenticator app — Google Authenticator, Microsoft Authenticator or Authy.
  • Scan the square below with it.
  • Enter the 6-digit code it shows you.

Can't scan it? Type the code above into your app by hand.

Keep the app installed — you'll need it every time you sign in.

Who is in it

Amend this class

The one person answerable for this class, and the name that shows on its card. Several people can teach a class — six Apas share the girls’ progression classes — but a card needs one name, not six. Leave it as “Not chosen” if you do not know. A guess looks exactly like a fact.

Who is in this class

Removing somebody here takes them out of this class. Their record stays, and so does every other class they are in.
