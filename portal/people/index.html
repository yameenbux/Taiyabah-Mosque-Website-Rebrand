Set up two-step verification

This screen holds staff records and contact details, so it needs a second factor before you can continue.

  • Install an authenticator app — Google Authenticator, Microsoft Authenticator or Authy.
  • Scan the square below with it.
  • Enter the 6-digit code it shows you.

Can't scan it? Type the code above into your app by hand.

Keep the app installed — you'll need it every time you sign in.
